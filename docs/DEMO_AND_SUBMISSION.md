## Problem
Students often choose meals using price alone. Comparing price with serving-level nutrition information can help them understand affordability trade-offs. The project provides a simple way to record meal options and compare them using consistent calculations.

Do not claim that all students face the same problem or quote prevalence figures unless independently researched and cited.

## Working prototype
The website lets a user add, edit and delete a meal using a real price and nutrition information; search records; import and export CSV; view calculated average price, average protein, best recorded protein affordability, median price and price range; compare price and protein in a chart; and enter a daily budget plus optional per-meal protein target to filter recorded options.

The app starts empty. Before recording the competition demo, enter actual meal options from a menu, receipt or reliable nutrition source. Do not present invented or illustrative figures as real observations.

Enter a realistic budget relevant to the collected menu prices. Run the analysis. Explain which recorded options fit the budget and the protein-affordability trade-off. Make clear that this compares individual meals, not a complete daily diet.

Explain how students can make more informed comparisons and how a canteen or student group could collect a larger, dated menu dataset. State that the current version stores data locally and that a real pilot is needed to measure actual behavioural or affordability outcomes.
