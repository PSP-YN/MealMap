# MealMap

MealMap is a student-focused food affordability and nutrition analytics website. It compares meal prices and user-entered nutrition values using transparent statistics. The application does not ship with sample records: every dashboard metric is calculated from records entered or imported by the user.

The project is being built for the INNOVATE online competition by team CHAKRAVYUHA.
