# Contributing to MealMap

Contributions are welcome. Keep the application lightweight, accessible and transparent.

## Principles
- Never add invented meal records or prefilled statistics.
- Keep formulas documented and deterministic.
- Label estimates and preserve source/serving-size context.
- Do not describe rule-based calculations as AI or machine learning.
- Avoid adding external services or paid API dependencies without a clear need.
- Keep the interface responsive and keyboard accessible.

## Local development
MealMap is a static website. Open index.html in a browser or run a local static server:

    python3 -m http.server 4173

Then visit http://localhost:4173.

There is no build step or package installation required.
